GEDASXH Portfolio — Version 2 (Multi-page)

PAGES
- index.html — Home
- about.html — About GEDASXH
- services.html — Services
- portfolio.html — Portfolio gallery with filters
- contact.html — Contact form that prepares a WhatsApp message
- style.css — Visual design, responsive layout, backgrounds and animations
- script.js — Mobile navigation, gallery filters, reveal animations, contact form

OPEN LOCALLY
1. Extract the ZIP.
2. Open the GEDASXH_Portfolio_v2 folder in Visual Studio Code.
3. Open index.html in your browser. All pages are linked through the navigation.
4. For editing, use VS Code. Live Server is optional.

IMPORTANT
- The portfolio artwork is CSS-made concept artwork, not your real completed client work. Replace it with your actual designs and project screenshots to build client trust.
- Confirm your WhatsApp number and email in the HTML files before publishing.
- The contact form opens WhatsApp; it does not send/store data on a server.
- Google Fonts is loaded online; fallback fonts are provided.
- This project is not hosted online yet.
